# PracticaCSSFinal - Responsive Web Design Project

## Project Description

This project is a basic website developed for the Fundamentals of Web Systems course. The main purpose is to practice HTML structure, external CSS files, semantic tags, visual design, forms, tables, multimedia elements, and responsive adaptation with media queries.

The website includes a new page called `portafolio.html`, created as an extension of the original project. This page presents a short learning portfolio about HTML, CSS, and responsive web design.

## Responsive Design

The project uses responsive design techniques to adapt the website to different screen sizes. The main CSS file includes media queries for screens of 700px or less. In small screens, the navigation menu changes its layout, forms use full width, tables avoid overflow, and images adjust to the available space.
